儲存位置

尚未選擇檔案

此瀏覽器不支援儲存到「本機檔案」（僅 Chrome / Edge 等 Chromium 系瀏覽器支援），將自動改用瀏覽器儲存。

瀏覽器儲存＝localStorage，只留在這台瀏覽器、這個網址底下，換瀏覽器或清除瀏覽資料會遺失；本機檔案則是直接寫入您指定的檔案，位置由您自己決定。無論選哪個，編輯時仍會即時寫入瀏覽器暫存做為意外重新整理時的復原備援，這裡的定時儲存是額外機制。

Markdown 是什麼？

Markdown 是一種輕量級的標記語法，讓你用純文字就能寫出有格式的內容。此編輯器另外支援 HackMD 常見的擴充語法，例如底線、螢光標記與定義清單。
